Code in the binaries

The zslice library, command line tool, and wasm module contain code from these projects. Their license texts are in licenses/.

ProjectLicenseTextNotes
Zig standard libraryMITlicenses/zig-std-MIT.txtThe compiler links the parts that zslice calls into each binary.
musl libc (math functions in the Zig standard library, for example atan2 and acos)MITlicenses/musl-MIT.txtThe Zig standard library has ports of musl math functions. The port keeps the musl notice.
Go (std.fmt.parseFloat in the Zig standard library is derived from Go strconv/atof.go)BSD-3-Clauselicenses/go-BSD-3-Clause.txtzslice parses numbers in ASCII STL files and in settings with parseFloat.
ARM optimized-routines (std.math.acos in the Zig standard library)MIT (dual MIT OR Apache-2.0 WITH LLVM-exception; zslice uses the MIT terms)licenses/arm-optimized-routines.txtsrc/offset.zig uses acos for round joins.
Khronos Vulkan headers (vendor/vulkan/include, version 1.4.350, copied from charttable)Apache-2.0 (the headers say SPDX-License-Identifier: Apache-2.0; the repository also allows MIT)licenses/vulkan-headers.txt, licenses/apache-2.0.txtThe types of the Vulkan renderer. The headers have declarations only. zslice loads the Vulkan loader at run time and does not link it.
Zig compiler_rt (parts ported from LLVM compiler-rt)MIT, and Apache-2.0 WITH LLVM-exceptionlicenses/zig-std-MIT.txtThe LLVM exception removes the notice requirement for compiled code. The entry is here for completeness.

zslice copies no code from other projects.

Algorithms, formats, and conventions

These sources gave methods or formats. zslice does not copy their code. Each zslice file that uses a source names it in its header comment.

SourceLicenseUsed inHow zslice uses it
Clipper2, Angus Johnson. https://github.com/AngusJohnson/Clipper2Boost Software License 1.0src/offset.zigThe offset method: move each edge along its normal, join at the vertices (miter, round, or a loop through the original vertex at a closing corner), then a union with the "positive" fill rule. zslice has its own implementation.
Bala R. Vatti, "A generic solution to polygon clipping", Communications of the ACM 35(7), 1992Papersrc/clip.zigNamed as the sweep-line method that Clipper uses. zslice uses a different method (planar arrangement and winding numbers).
Winding numbers and fill rules (even-odd, non-zero, positive)General computational geometry; the names follow the SVG and PostScript fill rules and Clipper2src/clip.zig, src/offset.zigThe rule that decides if a point is inside a polygon set.
Shoelace formula for polygon areaMathematicssrc/geom.zigThe signed area of a polygon.
John Amanatides and Andrew Woo, "A Fast Voxel Traversal Algorithm for Ray Tracing", Eurographics 1987Papersrc/clip.zigThe walk of an edge through the cells of the uniform grid that finds candidate crossings.
Doubly connected edge list (half-edge structure), as in de Berg et al., "Computational Geometry: Algorithms and Applications"Textbook methodsrc/clip.zigThe faces of the arrangement, walked to find the winding numbers.
Cura profile files (Ultimaker Cura, https://github.com/Ultimaker/Cura): .def.json definitions with inherits and overrides, .inst.cfg files with a [values] section, .xml.fdm_material materials, and the setting namesLGPL-3.0 (Cura; the formats and the names, not code)src/import_cura.zigThe import of a Cura profile stack.
TOML v1.0.0, https://toml.io/en/v1.0.0MIT (the specification)src/toml.zig, src/profile.zigThe profile file format. zslice parses a subset.
OctoPrint REST API, https://docs.octoprint.org/en/master/api/ (/api/printer, /api/printerprofiles, /api/job, /api/files/local, the X-Api-Key header)AGPL-3.0 (OctoPrint; the API, not code)linux/src/net/printer-link.cRead the state of a printer, and send G-code to it. printdeck has the same API.
Moonraker API, https://moonraker.readthedocs.io/ (/printer/objects/query, /server/files/upload)GPL-3.0 (Moonraker; the API, not code)linux/src/net/printer-link.cThe same, for Klipper printers.
printdeck deck API (same author, AGPL-3.0), deck/internal/octoapi of printdeck: /api/plugin/printdeck (the filament, the spools, the job)AGPL-3.0linux/src/net/printer-link.cThe filament in the printer, for "Use the filament in the printer".
G-code over a serial port: one command, then wait for the line ok (the Marlin and RepRap host protocol), https://reprap.org/wiki/G-codeProtocollinux/src/net/printer-link.cThe USB connection.
Tree support: the idea of branches that hold overhangs at points and join on the way down, as in Cura "tree support" (LGPL-3.0/AGPL-3.0) and PrusaSlicer "organic support" (AGPL-3.0)Idea; no codesrc/tree_support.zigzslice has its own method: tips on a fixed grid, moves limited by the branch angle, joins of nodes that touch, and a radius that gets smaller in narrow spaces.
STL file format, 3D Systems. Description: https://en.wikipedia.org/wiki/STL_(file_format)File formatsrc/mesh.zigThe binary and ASCII STL loader and the binary STL writer.
Integer coordinates in micrometers, as in CuraEngine (https://github.com/Ultimaker/CuraEngine)AGPL-3.0src/geom.zigThe coordinate unit. CuraEngine uses 1 unit = 1 micrometer (include/types/Coord_t.h). zslice uses the same unit. No code is copied.
CuraEngine G-code comments: ;FLAVOR:, ;LAYER_COUNT:, ;LAYER:n, ;TYPE:WALL-OUTER, WALL-INNER, SKIN, FILLAGPL-3.0 (the convention, not code)src/gcode.zigThe comment names, so that G-code viewers and printdeck (deck/internal/gcode/gcode.go) find the layers and features.
The gyroid, a triply periodic minimal surface (Alan Schoen, 1970), with the common approximation sin x cos y + sin y cos z + sin z cos x = 0. Gyroid infill is in CuraEngine and PrusaSlicerMathematics (the surface); general slicer technique (its use as infill)src/infill.zigThe gyroid infill pattern. zslice solves the equation for one coordinate in closed form.
The Slic3r flow model: the cross section of an extruded bead is a rectangle with half circles on the sides (Slic3r and PrusaSlicer, Flow.cpp, and the Slic3r manual)AGPL-3.0 (the model, not code)src/flow.zigThe plastic volume for each line, and the bead width in the 3D view.
Scanline polygon fill (sort the edge crossings on each line, fill between them by winding number)General computer graphics techniquesrc/infill.zigThe line infill.
Triangle, cubic, and concentric infill, as in CuraEngine and PrusaSlicerGeneral slicer technique (the patterns, not code)src/layer.zig, src/infill.zigThe triangles, cubic, and concentric infill patterns.
Greedy nearest-neighbor path orderGeneral techniquesrc/layer.zigThe order of the paths in a layer.
Mathematical morphology "opening" (erode, then dilate)General techniquesrc/offset.zig, src/layer.zigRemoves skin areas that are too thin to print.
Slab index (bucket edges into equal bands of one axis, then cast a ray only against one band)General techniquesrc/clip.zigFinds the edges that a winding ray crosses.
Compressed sparse row (CSR) layout: one array of items and one array of start offsetsGeneral techniquesrc/clip.zig, src/slicer.zigThe slab index and the per-layer face index.
Cut plane at the middle of each layerGeneral slicing practicesrc/slicer.zigThe z where the mesh is cut for each layer.
Joining cut segments by the ID of the mesh edge that they crossGeneral mesh techniquesrc/slicer.zigMakes closed loops from the segments of a layer without a coordinate tolerance.
Polyline simplification with an anchor point and a distance boundGeneral techniquesrc/geom.zigRemoves points that change a shape by less than the tolerance.
PrusaSlicer G-code comment name ;TYPE:Ironing (https://github.com/prusa3d/PrusaSlicer)AGPL-3.0 (the convention, not code)src/gcode.zigzslice writes ;TYPE:IRONING. printdeck reads the name in lowercase.
Lookout Marine, linux/src/engine/surface.c (same author, MIT license)MITlinux/src/ui/native-surface.cAdapted: a Wayland subsurface under the GTK window, with an empty input region, for the Vulkan view.
charttable, src/gpu/gpu_vk.zig (same author, MIT license)MITsrc/render/vk.zigThe structure of the Vulkan backend: run-time loading of the loader, a surface from the shell, a swapchain sized by the host, a UNORM swapchain format, and SPIR-V words copied at comptime. The code is new.
Lookout Marine (same author): a Zig core with a C API and one native shell for each platformSame authorsrc/app.zig, linux/The structure of the app: the core has the logic, and each shell draws widgets, does file I/O, and moves events to its UI thread.
Grid ("normal") support: overhang by angle, columns down to the bed or the part, XY and Z gaps, dense interface layers. As in CuraEngine and PrusaSlicerGeneral slicer technique (the method, not code)src/support.zigThe support areas of each layer.
PKWARE, ".ZIP File Format Specification" (APPNOTE.TXT), https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXTPublic specificationsrc/zipfile.zigThe zip records (local header, central directory, end record, and the zip64 records and extra field). The header structs and deflate come from the Zig standard library (MIT).
3MF Consortium, "3MF Core Specification" 1.3 and "Production Extension", https://github.com/3MFConsortium/spec_coreBSD-2-Clause (the specification)src/threemf.zigThe 3MF package, the model file, objects, components, build items, transforms, and units. The code is new.
Christer Ericson, "Real-Time Collision Detection" (2005), 5.1.5: the closest point on a triangleGeneral computational geometry techniquesrc/plate.zig (pointTriangle2)The side of a part nearest to a picked point, for "this side on the bed".
Auto orientation of a part for less support (the method of the "Tweaker" auto-rotation of Cura and PrusaSlicer: score candidate directions by overhang area, bed contact, and height)General slicer technique (the method, not code)src/orient.zigThe best orientation of a part for the smart, less-support, and strength placements.
Iterated snap rounding (repeat the intersection pass on the rounded result)General computational geometry techniquesrc/clip.zigMakes the boolean operations robust after crossing points are rounded to the grid.
Least significant digit radix sort (a stable counting sort for each digit, from the low digit to the high digit)General techniquesrc/clip.zigSorts the cell entries of the crossing grid by cell.
A. M. Andrew, "Another efficient algorithm for convex hulls in two dimensions", Information Processing Letters 9(5), 1979 (the monotone chain)Papersrc/offset.zigThe convex hull of a loop, for the test that a loop vanishes in an offset.
A convex shape with an inscribed circle of radius r has area A >= r P / 2 (P is the perimeter)Mathematicssrc/offset.zigThe bound r <= 2 A / P on the largest circle in a convex hull.
Uniform grid search for the nearest point, ring by ringGeneral techniquesrc/layer.zigFinds the nearest path start in the greedy path order.
Memoization: keep a result with the inputs that made it, and use it again for the same inputsGeneral techniquesrc/layer.zig, src/engine.zigThe memo of each layer, which keeps the slow results between slices.
Arena allocators kept in a pool and reset between usesGeneral techniquesrc/scratch.zigThe work memory of the booleans and offsets.

Test tools

zslice runs these programs in its test tools. No code of these programs is in zslice.

ProgramLicenseUsed inHow zslice uses it
