Printables

zslice reads the list of files of a public Printables model, and the download link of each file that the user checks. See Import a model from a model page. zslice copies no code from these sources. It uses the facts of the API: the address, the names of the query and the fields, and the forms of the answers.

  2. Projects that use the API

The API and the terms

The Printables GraphQL API

License
The API (facts, no code); the terms of the Prusa sites
Link
https://www.printables.com
Version
The API as the model page of printables.com sends it, read on 2026-11-22
Used in

The endpoint is https://api.printables.com/graphql/ (the slash at the end is necessary). It needs no key and no login for a public model. Its introspection is off, and it has no public documentation.

  • The query print(id: $id) gives the model: name, user { publicUsername }, license { name }, stls (each model file: STL, 3MF, STEP, and OBJ, despite the name), and otherFiles. Each file has id, name, folder, fileSize, and filePreviewPath (a path on https://media.printables.com/).
  • The mutation getDownloadLink(id, printId, fileType: stl, source: model_detail) gives output { link }: a URL on files.printables.com. The site counts it as a download.
  • CORS: the API answers only the origin https://www.printables.com. The files and the previews send Access-Control-Allow-Origin: *. So the web app of zslice cannot read the list.

The terms: the Terms of Service of Printables (from 15 October 2026) and the General Terms of the Prusa websites (from 20 April 2026, article 9). Article 9.1 asks for use "in the usual manner", and forbids automated extraction, scraping, and a load that burdens the service. zslice does what the model page does for one user: it asks for one model when the user pastes its address, and downloads only the files that the user checks, one at a time. It keeps no copy of the list, and it sends zslice/<version> (+https://github.com/beetlebugorg/zslice) as its User-Agent.
