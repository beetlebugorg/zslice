# The Cura settings (fdmprinter.def.json and fdmextruder.def.json) and
# zslice. tools/setting_coverage.py reads this file.
#
# One line for each key: key | status | text
#   same     zslice has the setting: the text names it.
#   derived  zslice does the same with no setting of its own, or another
#            zslice setting covers it: the text says how.
#   missing  zslice does not have it yet: the text says what it does.
#   not      not for zslice: the text says why.
# A key with no line here is "missing" in the table.
